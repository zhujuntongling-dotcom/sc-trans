# 图片重绘：保持版式，只换语言

位图里的文字改不了，只能**照着原图重画一张**。目标是"同一版式语言"，不是像素级复刻。

## 一、先测量

用 `images.py list` 或直接看原图，记下：

- 像素尺寸与宽高比（例如 512×640 = 4:5）
- 主色（背景、主色块、强调色）——直接取像素值，不要凭感觉
- 卡片/图表的结构：几行几列、圆角半径、是否有阴影、是否有折角
- 字号层级：标题 / 日期条 / 正文各多少 px
- 特殊标记：高亮色块（比如关键日期）、虚线分隔、图标

## 二、再重绘

- 画布：**按原比例放大 2 倍**（512×640 → 1024×1280）。比例不变，文档里的显示尺寸就不会变。
- 字体：中文用 `msyhbd.ttc`（标题）/ `msyh.ttc`（正文），路径 `C:\Windows\Fonts\`。
- 配色：直接沿用测到的 RGB，不要"美化"。
- 文字：**必须自动换行 + 限行数**，超出就缩字号，不要溢出卡片。
- 换行坑：中文标点（`）`、`，`）不要落在行首——手写折行时把标点粘在前一个字后面。

## 三、写回文档

```bash
python scripts/images.py replace --docx 译文.docx --work _work
```

它只替换 `word/media/*` 的字节，**不动 `document.xml`**，所以位置、大小、环绕方式全部保持原样。

> 关键：重绘文件必须用**原文件名**（如 `image1.jpeg`）保存到 `_work/images/`，替换才命中。

## 四、验收

- 宽高比与原图一致（`verify.py` 会算）
- 放大到 100% 看：文字没有溢出、没有压住图形、没有截断
- 与原图并排看：结构、留白、强调色位置一致

## 五、什么时候别硬做

- 照片类插图（风景、人物）里的文字：没有版式可循，建议在图下加中文图注，而不是重绘。
- 手绘/复杂插画：重绘成本高于收益，同理加图注并在文中说明。
